# 来源库方案（定稿，2026-10-27）

## 命名
- 概念「来源」（去「书证」前缀，来源天然属于书证）；库名「来源库」。
- 单字「源」作代码/紧凑用。备选「文献」不推（构拟非文献）。

## 列
| 列 | 类型 | 说明 |
|---|---|---|
| 名 | text（键） | 「廣韻」「斯氏上古早期」 |
| 类型 | 韵书/辞书/构拟 | 韵文不成来源 |
| 音系 | Maybe(音系名) | 韵书/构拟 → 音系节点；纯辞书置空 |
| 时代 | 全序值 | 描述时空（见下）；纯辞书退成书年 |

## 时代拟构
汉语演进节点（全序；冒号后为朝代参考，非绝对标准）：

原始 → 早期上古 → 晚期上古 → 早期中古 → 晚期中古 → 近代 → 现代

- 原始：汉语支分化–商朝早期
- 早期上古：商周–西汉
- 晚期上古：东汉
- 早期中古：魏晋–中唐
- 晚期中古：盛唐–宋
- 近代：元以降
- 现代：民国以降

命名约定：「xx漢語」去「漢語」后缀。

## 时代之准
描述时空（音系时代），非成书年。理由：
- 构拟成书现代、描述上古 → 成书年会错乱。
- 廣韻成书北宋、音系唐 → 音韵库取唐。
- 纯辞书无音系 → 退成书年（说文=东汉）。
