## 一句话结论

> 书证库存「字形 × 音类 × 时代 × 源」的扁平节点，字形库存「码点 × 结构 × 分类」的 identity 节点；扩充数据源以 Unicode Unihan（字形 + 简繁异体边 + 现代音 + 域外音）、韻典網 ytenx（中古韵书 + 上古音系）、CHISE IDS（部件）为三大免费开放支柱，广韵原地迁入并顺手拆出 CSV 里已埋的切韵/玉篇/经典释文/先秦韵部。

## 书证字段

「已定」四个保留；「提议」为下层新增。

| 字段 | 类型 | 归属 | 说明 |
|---|---|---|---|
| glyph | Maybe<GlyphId> | 已定 | 字形库外键；只知读音无字形者 Nothing |
| reading | Maybe<音类> | 已定 | 某音系下的音韵地位（值、无 ID）；转写是它的投影 |
| era | Era | 已定 | 时代；判同代/跨代的数据性 |
| source | Source | 已定 | 书目引用（书名 + 版本 + 卷/页） |
| head | string | 提议 | 源书原文字头（未规整，可含异体/缺字），规整后才指 glyph |
| sourceKey | string | 提议 | 源内稳定定位（卷/小韵序/字序），自然键成分 |
| gloss | Maybe<string[]> | 提议 | 训释/义项（源书原文）；**不进身份** |
| examples | Maybe<Quote[]> | 提议 | 文献例句（引句 + 出处）；二期 |

**反思（义的归属）**：书证定名时淘汰「音证（窄化为音）」，说明书证不限音；广韵/玉篇/说文条目天然带训释，README 也明列释义。故「义」应作书证的**内容字段**（gloss，源书原文，属「记录」不属「解读」）。但它**不进身份**——义不稳定、可引申/假借/重分析，进身份会过度分裂且依赖理论，违背「良定义只在记录层」。这同时回应上层承重墙「义要不要进身份」：不进。

**反思（reading 的形状）**：reading 不是自由字符串。它是「某音系下的音类」，音类由音系 schema 定义分量，转写由同一 schema 定义单射序列化。不同音系音类形状不同——中古晚期 = 声/摄/韵/调/等/呼，中古早期 = 反切(上字+下字)，现代 = 声/韵/调，域外 = 音读/训读。上层 PhonologyRecord 的 union 正是这个多态；「反切」不是独立字段，而是「中古早期」音系下 reading 的形状。

## 字形字段

上层面已给 GlyphInfo 的 identity/composition；本层把它落成独立字形库节点，音韵字段**移出**（音韵属书证）。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | GlyphId | 自然键 = Unicode 码点；CJK 统一冲突用「码点 + 变体选择符/地区标记」补足，首版先以码点为准、地区差异存字段 |
| codepoint | string | U+XXXX |
| classifications | Classification[] | 传承字/简化字/二级简化字（已有）+ 日本新字体/韩国汉字/越南喃字（扩展） |
| properties | Property[] | 声旁/次级声旁（已有）+ 部首 |
| method | 六书 | 形声/会意/象形/指事/转注/假借/整体/复声/叠声 |
| shapes | GlyphId[] | 义符/形旁（部件外键） |
| sounds | GlyphId[] | 声符/声旁（部件外键） |
| ids | string[] | IDS 序列（CHISE），部件分解主源 |
| radical | GlyphId | 部首（Unihan kRSUnicode） |
| residualStrokes | number | 部首余笔 |
| totalStrokes | number | 总笔画 |
| sources | Source[] | 字形出处（Unihan/GlyphWiki/说文小篆/各标准） |

**反思（声旁从字符串升级为外键）**：现有 guang-yun.mts 的声旁/义符是 string（shengXing_Sheng / shengXing_Xing），dev/声符字典 靠字符串递归查声旁。本层把它们规整为 GlyphId[]，与字形→字形「部件」边一致。这样声符系联从「字符串递归」升级为「图遍历」，正好交给扩张算子——这是与现有系统合得拢的关键改造。

## 关系（边）

两张图，类型确定、带来源（上层已定）。以下填具体边型。

**书证 → 书证**

| 边型 | 语义/方向 | 时代 | 来源 |
|---|---|---|---|
| 祖先 derivation | 上代书证 → 下代书证 | 跨代 | 音变谱系/声符系联/词族 |
| 文白读 colloquial-literary | 文读 ↔ 白读 | 同代 | 现代字典 |
| 破读 derivation-by-tone | 本读 → 破读（好 hǎo/hào） | 同代 | 训诂/现代字典 |
| 等价 equivalence | 不同源同音类互证 | 同代 | 多源比对 |
| 转注 transfer | 考 ↔ 老 | 字际 | 说文六书 |
| 假借 loan | 本字 → 借字（其→箕） | 字际 | 训诂 |
| 同源 cognate | 同源词族成员 | 跨代 | 白-沙词族/王力同源字典 |

**反思（不设「异读」边）**：多音字 = 同 glyph 下多个书证（不同 reading）。其成因若属文白/破读则标对应边，否则就是彼此独立的书证、无显式边。设「异读」边会把「成因」和「现象」混成一条模糊边，筛掉。

**字形 → 字形**

| 边型 | 语义 | 来源 |
|---|---|---|
| 部件 component | A 含部件 B（A → B） | CHISE IDS / 说文 |
| 简繁 simplification | 让 ↔ 讓 | Unihan kSimplified·TraditionalVariant |
| 异体 variant | 同字异形（含地区，峯/峰、爲/为） | Unihan kZVariant / 说文 |
| 语义变体 semantic-variant | 同义异形 | Unihan kSemanticVariant |
| 兼容变体 compatibility | 兼容字符 → 规范字符 | Unihan kCompatibilityVariant |

**跨库不设边**：书证.glyph_id → 字形库只是字段查找（上层已定「扩张算子不跨库」）。字形 → 书证的反向靠按 glyph_id 索引，非图遍历。

## 算子

**基算子（测量，A → Maybe<B>，上层已定形状）**

书证域：glyph / reading(音系) / transcription(音系) / era / source / gloss / 声母·韵母·声调·等·呼·摄（中古音系分量）。
字形域：codepoint / radical / strokes / ids / method / shapes / sounds；反向 attestations(字形) → Collection<书证>（字段查找）。

**组合子**：fmap / join(flatten) / filter / bind(flatMap)（已定）。flatten 有损（丢系/字形归属），保留结构化变体。

**扩张算子（已定）**：扩张(种子, 条件) → Collection<书证>，只跑书证库。提议具体条件谓词：

| 条件 | 语义 | 默认 |
|---|---|---|
| 同字 | 同 glyph_id，或经简繁/异体边连通 | 是（默认） |
| 同声符 | 沿字形部件边回溯到同一声符 | 否 |
| 同韵部 | 中古音类韵部相同 | 否 |
| 同声母 | 中古音类声母相同 | 否 |
| 同源 | 沿祖先/同源边连通 | 否 |

**蓝图工具消费（衔接蓝图原型引擎）**：源 source / 筛选 filter / 扩张 expand / 测量 measure / 聚合 count·ratio·groupBy·distinct / 比较 compare（对应 README 音韵对比浮窗）。

## 音系与转写

| 音系 | era | 音类结构 | 权威转写 |
|---|---|---|---|
| 上古 | 上古 | 韵部 + 声母类（+ 介音） | 待定（见下） |
| 中古早期 | 中古 | 反切（上字 + 下字） | 切韻反切 |
| 中古晚期 | 中古 | 声/摄/韵/调/等/呼 | 廣韻音韵地位 |
| 近古 | 近古 | 声/韵/调 | 中原音韻 |
| 现代·普通话 | 现代 | 声/韵/调 | 汉语拼音 |
| 现代·粤语 | 现代 | 声/韵/调 | 粤拼 |
| 现代·闽南 | 现代 | 声/韵/调 | 台罗/白话字（dev 已有 banlam.csv） |
| 现代·吴/客/赣… | 现代 | 声/韵/调 | 各家 |
| 域外·日/韩/越 | 域外 | 音读/训读 | 罗马字/谚文/国语字 |

**反思（上古的分歧）**：白-沙、郑张、王力、李方桂的「韵部框架」本身有出入，不只是转写差异。故上古不能简单视为「单音类多转写」。提议：上古拆为「音系变体」——每家的韵部框架是独立音类体系，各自选自己的权威转写；若两家韵部可映射，则后者降为「辅助转写字段」。默认倾向：音类 = 王力韵部（最通用），权威转写 = 白-沙（最系统），其余家作辅助转写。**此点属待定承重墙，需你拍板选谁。**

| 身份判定 = (字形, 读音) 够不够 | 够。义/部件/假借不进身份；文白异读 = 同字形同音系两个书证（靠文白读边关联），不进身份，否则「血」裂成两字。多音 = 同 glyph 多书证，非多字 |

## 分期（两周级小闭环）

- 一期：广韵迁入书证库 + 拆 CSV 已埋列（切韵/玉篇/经典释文/先秦韵部）为多源 + 接 Unihan（字形库 + 简繁异体边 + 现代/域外音书证）。产出书证库 + 字形库可查询、GlyphInfo 聚合视图可用。
- 二期：CHISE IDS（部件边）+ ytenx（中古韵书结构化 + 上古音系）+ 说文（字源书证）。
- 三期：Wiktionary（各家拟音/方音）+ ctext（例句）+ 白-沙词族（同源/祖先边）。
